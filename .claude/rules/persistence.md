# Persistence Rules — SQLiteData + UserDefaults

**Stack**: SQLiteData (PointFree) — GRDB + StructuredQueries — for regenerable cache data.
**UserDefaults**: non-regenerable user input (playlists, favorites) + scalar flags (last channel id, EPG TTL timestamp, volume).

## Why the split

tvOS gives no persistent local file storage the way iOS does. Only `UserDefaults` is
guaranteed to survive (~500KB limit). `Library/Caches` — where `stanislove.sqlite`
lives (`DatabaseStack.live()`) — can be purged by the system at any time under storage
pressure, with no backup.

So the rule is: **anything the user typed in and can't be recreated goes in
`UserDefaults`. Anything derived from a remote source goes in SQLite, because losing
it just means re-downloading and re-parsing.**

| Data | Where | Why |
|------|-------|-----|
| Playlists (`id`, `name`, `urlString`, `type`, `epgURL`, `lastFetched`) | `UserDefaults` (`DefaultPlaylistRepository`, actor) | User-entered, not regenerable |
| Favorites (`Set<String>` of `Channel.favoriteKey`) | `UserDefaults` (`DefaultFavoriteRepository`, actor) | User-entered, not regenerable |
| `channels` | SQLite (`Caches`) | Regenerated by re-parsing the playlist's M3U |
| `epgPrograms` | SQLite (`Caches`) | Regenerated by re-fetching the playlist's XMLTV |

If `Caches` gets purged, `RehydrateCacheUseCase` re-downloads and re-parses channels
for every playlist still in `UserDefaults` whose SQLite channel count is zero — see
"Rehydration" below.

## Favorite identity

`Channel.id` is a fresh `UUID()` generated on every M3U parse (`M3UParser.swift`), so
it cannot be used as a stable favorite key — a channel refresh would silently orphan
all favorites. Use `Channel.favoriteKey` instead:

```swift
var favoriteKey: String { tvgID ?? streamURL.absoluteString }
```

`tvgID` is preferred (stable across refreshes); `streamURL` is a fallback for
providers that omit `tvg-id`, and is only unreliable if that same provider also
tokenizes URLs between refreshes.

## Tables (SQLite — channels/EPG only)

| Table | Purpose |
|-------|---------|
| `channels` | Parsed channels per playlist (`playlistID` is a plain value, no FK — see below) |
| `epgPrograms` | EPG cache (pruned at 48h) |

`playlists` and `favorites` tables were dropped in migration `v3` — see Migrations
below.

## @Table Structs

`nonisolated struct` is required — `@Table` does not support `class` or `actor`-isolated types.

```swift
@Table nonisolated struct ChannelRecord: Identifiable {
    let id: UUID
    var playlistID: UUID   // no FK — playlists live in UserDefaults, not SQLite
    var name: String
    var streamURL: String
    var logoURL: String?
    var groupTitle: String
    var tvgID: String?
    var position: Int
}

@Table nonisolated struct EPGProgramRecord: Identifiable {
    let id: UUID
    var channelID: String   // matches Channel.tvgID
    var title: String
    var startTime: Date
    var endTime: Date
    var programDescription: String?
    var fetchedAt: Date     // for TTL pruning
}
```

## UserDefaults records

Plain `Codable` structs, JSON-encoded into a single `Data` blob per key (not
`@Table`). No SQLite involved.

```swift
struct PlaylistDefaultsRecord: Codable, Identifiable, Sendable {
    let id: UUID
    var name: String
    var urlString: String
    var typeRaw: String
    var epgURLString: String?
    var lastFetched: Date?
}
```

Favorites are stored even more simply: `Set<String>` of `Channel.favoriteKey`,
JSON-encoded under `PersistenceKeys.favoriteChannelKeysV1`.

Keys live in `Core/Constants/PersistenceKeys.swift` — no magic strings.

## DatabaseStack

```swift
struct DatabaseStack {
    let writer: any DatabaseWriter

    static func live() throws -> DatabaseStack {
        let url = try FileManager.default
            .url(for: .cachesDirectory, in: .userDomainMask, appropriateFor: nil, create: true)
            .appendingPathComponent("stanislove.sqlite")
        var config = Configuration()
        config.foreignKeysEnabled = true
        let queue = try DatabaseQueue(path: url.path, configuration: config)
        var migrator = DatabaseMigrator()
        Migrations.register(in: &migrator)
        try migrator.migrate(queue)
        return DatabaseStack(writer: queue)
    }
}

extension DatabaseStack: DependencyKey {
    static let liveValue: DatabaseStack = {
        do { return try DatabaseStack.live() }
        catch { fatalError("Failed to open database: \(error)") }
    }()
    static let testValue = DatabaseStack(writer: try! DatabaseQueue()) // in-memory
}

extension DependencyValues {
    var database: DatabaseStack {
        get { self[DatabaseStack.self] }
        set { self[DatabaseStack.self] = newValue }
    }
}
```

Deliberately in `Caches`, not `Application Support` — this is not an oversight. It
signals (correctly) that the file is disposable cache, matching how the app actually
treats it.

## UserDefaultsClient

Thin `DependencyKey` wrapper over `UserDefaults`, so repositories built on it stay
testable the same way SQLite repositories are (real backing store, swapped via
`withDependencies`, not a hand-rolled mock):

```swift
struct UserDefaultsClient: Sendable {
    var data: @Sendable (String) -> Data?
    var setData: @Sendable (Data?, String) -> Void
    var stringArray: @Sendable (String) -> [String]?
    var setStringArray: @Sendable ([String]?, String) -> Void
}

extension UserDefaultsClient: DependencyKey {
    static var liveValue: Self { /* wraps UserDefaults.standard */ }
    static let testValue = UserDefaultsClient(/* unimplemented(...) on every closure */)
}
```

In tests, don't use `.standard` — point at an ephemeral suite so tests can't leak
into each other or the host machine:

```swift
let defaults = UserDefaults(suiteName: "test-\(UUID().uuidString)")!
```

## Migrations — always use `#sql` macro + `DatabaseMigrator`

```swift
enum Migrations {
    static func register(in migrator: inout DatabaseMigrator) {
        migrator.registerMigration("v1_initial") { db in
            // channels, epgPrograms, and (historically) playlists/favorites
        }
        migrator.registerMigration("v2_playlist_epg_url") { db in
            // ALTER TABLE playlists ADD COLUMN epgURL — dead now that playlists
            // moved out of SQLite, kept only because migrations are never edited
        }
        migrator.registerMigration("v3_move_playlists_favorites_to_userdefaults") { db in
            // 1. Recreate "channels" without its FK to "playlists" (SQLite has no
            //    ALTER TABLE ... DROP CONSTRAINT) — must happen before the DROP below,
            //    or the still-referencing FK blocks it.
            // 2. DROP TABLE "favorites"
            // 3. DROP TABLE "playlists"
        }
        // Each future schema change = new registerMigration("v4_...") block
        // Migrations are irreversible — never DROP columns or tables without a new version
    }
}
```

**Never edit** `v1_initial` / `v2_playlist_epg_url` / `v3_move_playlists_favorites_to_userdefaults`
— only add new versions.

## Repository Pattern

SQLite repositories (`channels`, `epgPrograms`): `class`, `db.writer.read { }` /
`db.writer.write { }`, `RecordType.Draft(...)` for inserts.

```swift
final class DefaultChannelRepository: ChannelRepository {
    @Dependency(\.database) private var db
    @Dependency(\.favoriteRepository) private var favoriteRepository

    func fetchAll(playlistID: UUID) async throws -> [Channel] {
        let channels = try await db.writer.read { database in
            try ChannelRecord
                .where { $0.playlistID.eq(playlistID) }
                .order(by: \.position)
                .fetchAll(database)
                .map(\.domainModel)
        }
        // Favorites live in UserDefaults, not SQLite — no SQL join. Resolve in memory.
        let favoriteKeys = try await favoriteRepository.fetchAll()
        return channels.map { channel in
            var channel = channel
            channel.isFavorite = favoriteKeys.contains(channel.favoriteKey)
            return channel
        }
    }
}
```

UserDefaults repositories (`playlists`, `favorites`): `actor` — `UserDefaults` has no
built-in read-modify-write serialization the way `DatabaseQueue` does, so the actor is
what prevents lost updates under concurrent access.

```swift
actor DefaultPlaylistRepository: PlaylistRepository {
    @Dependency(\.userDefaultsClient) private var defaults

    func insert(_ playlist: Playlist) async throws {
        var records = loadRecords()
        records.append(.from(playlist))
        saveRecords(records)
    }

    private func loadRecords() -> [PlaylistDefaultsRecord] {
        guard let data = defaults.data(PersistenceKeys.storedPlaylistsV1) else { return [] }
        return (try? JSONDecoder().decode([PlaylistDefaultsRecord].self, from: data)) ?? []
    }
    // Corrupted/missing JSON decodes to [] rather than throwing — UserDefaults isn't
    // a database, callers shouldn't need to handle decode failures for cold-start state.
}
```

Deleting a playlist no longer cascades via SQL FK (the FK was removed in `v3`).
`DeletePlaylistUseCase` is the only thing preventing orphaned channel rows — it must
call both `playlistRepository.delete(id:)` and `channelRepository.deleteAll(playlistID:)`.

## Rehydration

`RehydrateCacheUseCase` runs after `PlaylistsViewModel.load()` on cold start. For each
playlist in `UserDefaults`, if SQLite has zero channels for it, it re-runs
`RefreshPlaylistUseCase` (download + parse + save) in the background. Best-effort per
playlist — one unreachable playlist doesn't block rehydrating the rest.

## Domain Mapping Convention

Every `@Table` struct (SQLite) and every `*DefaultsRecord` struct (UserDefaults) has a
`domainModel` extension in the same file — the only place where storage type → Domain
entity conversion happens.

```swift
extension ChannelRecord {
    var domainModel: Channel {
        Channel(
            id: id,
            name: name,
            streamURL: URL(string: streamURL)!, // safe: validated at M3U parse time
            logoURL: logoURL.flatMap(URL.init),
            groupTitle: groupTitle,
            tvgID: tvgID,
            isFavorite: false // resolved separately, in memory, against UserDefaults
        )
    }
}
```

Reverse mapping (Domain → Draft / Domain → DefaultsRecord) lives as a static factory
or free function in the same file.
